# StoryPilot
FastAPI + React, Gemini on Vertex AI, Firestore, read-only Jira and Confluence connectors.
Start with `docs/SETUP_GUIDE.md`. Design and limits: `docs/ARCHITECTURE.md`.
Quick offline demo: `cd backend && pip install -r requirements.txt && uvicorn app.main:app --port 8080`, then `cd frontend && npm install && npm run dev`.
